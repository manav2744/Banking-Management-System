# 🏦 Banking Management System

A responsive Banking Management System developed using **HTML5, CSS3, and JavaScript**. This project simulates basic banking operations such as customer management, deposits, withdrawals, fund transfers, and transaction history using **Local Storage** for data persistence.

---

*Note:** This project uses browser **Local Storage** to simulate data persistence. It is intended for educational purposes and demonstrates frontend development concepts using HTML, CSS, and JavaScript.

---

## 📌 Features

- 🔐 Admin Login
- 👥 Add, Edit, and Delete Customers
- 🔍 Search Customers
- 💰 Deposit Money
- 💸 Withdraw Money
- 🔄 Transfer Money Between Accounts
- 📜 Transaction History
- 💾 Local Storage for Persistent Data
- 📱 Responsive User Interface
